# 🌐 Contexto da Disciplina

> 💡 **Por que estudar Frameworks Front-end?**

Atualmente, boa parte das aplicações Web modernas utiliza algum tipo de **Framework Front-end**.

No ambiente empresarial, existe a necessidade de desenvolver interfaces que sejam:

| 🚀 Característica         | 📌 Importância                          |
| ------------------------- | --------------------------------------- |
| ⚡ **Rápidas**             | Melhor experiência durante a utilização |
| 🧩 **Organizadas**        | Facilita o desenvolvimento e manutenção |
| 🔧 **Fáceis de manter**   | Permite evolução contínua da aplicação  |
| 📱 **Responsivas**        | Adaptação a diferentes dispositivos     |
| 👤 **Focadas no usuário** | Melhora a experiência de utilização     |

### 🏢 Importância empresarial

O desenvolvimento Front-end é apresentado como um **requisito estratégico**, sendo importante para a competitividade empresarial.

Além disso, está relacionado à **arquitetura de software**, considerando como diferentes partes de uma aplicação se conectam para melhorar seu funcionamento.

---

# 💻 O que é Desenvolvimento Front-end?

> 🧠 **Front-end** é a camada de uma aplicação com a qual o usuário interage diretamente.

Essa camada é responsável principalmente pela construção da interface e pela experiência de utilização.

### 🎨 Principais responsabilidades

* 🖼️ Criação das interfaces;
* 📐 Organização visual dos elementos;
* 👤 Experiência do usuário;
* 🔗 Comunicação com os sistemas responsáveis pelo processamento dos dados.

# 🟨 JavaScript — Vanilla JS

## 📌 O que é JavaScript?

O **JavaScript** é apresentado na aula como uma **linguagem de script interpretada**, sendo essencial para o desenvolvimento Front-end.

### 🟨 Vanilla JavaScript

> 💡 **Vanilla JS = JavaScript puro, sem dependências externas.**

Ele serve como base para diferentes abstrações utilizadas no desenvolvimento Front-end.

### ⚙️ O que podemos fazer?

O JavaScript permite:

* 🖱️ Manipular páginas;
* 🧠 Implementar lógica de interface;
* 🌐 Realizar comunicação com servidores.
